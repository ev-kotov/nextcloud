# nextcloud

# Стек Nextcloud на базе Rootless Podman и Mise

Современное, безопасное и изолированное решение для развертывания персонального облака **Nextcloud** с использованием **Rootless Podman** (запуск без прав root/sudo) под управлением автоматизации **Mise**.

## 🏗️ Архитектура стека

Стек состоит из следующих изолированных компонентов:
*   **Nextcloud App (`nextcloud:fpm-alpine`)** — основное приложение Nextcloud, работающее через быстрый протокол FastCGI.
*   **Nextcloud Cron (`nextcloud:fpm-alpine`)** — фоновый планировщик задач Nextcloud (работает внутри контейнера каждую минуту).
*   **Nextcloud Nginx (`nginx:alpine`)** — веб-сервер, который отдает статические файлы и проксирует PHP-запросы в контейнер приложения.
*   **Nextcloud DB (`postgres:17-alpine`)** — СУБД PostgreSQL 17, запущенная под суперпользователем `postgres` во избежание проблем с правами в схеме `public`.
*   **Nextcloud Redis (`redis:alpine`)** — кэш данных и блокировщик файлов для ускорения интерфейса.

Вся связка работает за внешним обратным прокси-сервером **Traefik**, который отвечает за автоматическую генерацию SSL Let's Encrypt сертификатов.

## 🚀 Пошаговое развертывание с нуля

Благодаря интеграции `mise`, развертывание выполняется в несколько прозрачных этапов.

### Шаг 1. Тотальная очистка старого кэша (Если запускается повторно)
Если вы уже пытались разворачивать стек, полностью затрите застрявшие тома и папки хоста, чтобы избежать конфликтов прав доступа Linux и СУБД:
```bash
mise run prod:clean
mise run prod:purge-data
```

### Шаг 2. Подготовка хоста и Rootless-прав
Эта команда автоматически установит системные зависимости (если их нет), создаст каталоги, пропишет SELinux-контексты (`container_file_t`) и настроит сопоставление UID хоста с пользователем `www-data` (UID 82) внутри Alpine:
```bash
mise run prepare
```

### Шаг 3. Запуск инфраструктуры контейнеров
Поднимите контейнеры в фоне через `podman-compose`:
```bash
mise run prod:up
```

### Шаг 4. Создание чистой базы данных
Принудительно создайте пустую базу данных в работающем инстансе PostgreSQL из-под суперпользователя:
```bash
mise run prod:db-init
```

### Шаг 5. Контролируемая установка таблиц
Запустите ручную нарезку таблиц Nextcloud. Команда дождется готовности контейнера и выполнит установку:
```bash
mise run prod:install
```
*Дождитесь заветного сообщения: `[OK] Nextcloud успешно установил все таблицы!`.*

### Шаг 6. Финальная конфигурация
Пропишите доверенные подсети Podman, доменное имя и принудительный HTTPS:
```bash
mise run prod:configure
```

## ⚡ Оптимизация производительности (Redis)

После успешного выполнения всех шагов и входа в интерфейс под пользователем `kot`, активируйте работу кэширования через Redis для ускорения генерации миниатюр и списков файлов:

```bash
mise run occ -- config:system:set memcache.local --value="\OC\Memcache\Redis"
mise run occ -- config:system:set memcache.locking --value="\OC\Memcache\Redis"
mise run occ -- config:system:set redis host --value="redis"
mise run occ -- config:system:set redis port --value="6379" --type=integer
```

## 🛠️ Полезные сервисные команды

*   **Просмотр живых логов всех контейнеров:**
    ```bash
    mise run logs:all
    ```
*   **Быстрый перезапуск стека:**
    ```bash
    mise run prod:down
    mise run prod:up
    ```
*   **Использование утилиты occ напрямую с хоста:**
    ```bash
    # Пример просмотра текущего статуса системы:
    mise run occ -- status
    ```
